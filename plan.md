🛸 Project Femmy: Advanced AI Discord BotThis document outlines the architecture, requirements, and feature set for "Femmy," a highly advanced Discord bot hosted on Oracle Cloud Infrastructure (OCI) using a modular Python framework and the Gemini AI API.🏗️ 1. Infrastructure & EnvironmentHost: Oracle Cloud (Always Free Tier).Machine: VM.Standard.A1.Flex (ARM Ampere).Specs: 4 OCPU, 24 GB RAM, 200 GB Storage.OS: Ubuntu 22.04 LTS.Security: * SSH Key-based authentication (Private key strictly localized)..env file for secret management (Discord Token, Gemini API Key).Oracle VCN Ingress Rules: Ports 80 (HTTP) and 443 (HTTPS) for future Portfolio hosting.🛠️ 2. Tech StackLanguage: Python 3.10+Library: discord.py (Async engine using Cogs).AI Brain: google-generativeai (Gemini Pro & Gemini Pro Vision).Database: aiosqlite (Asynchronous SQLite).Tables needed:user_facts: Stores !remember data.user_settings: Stores timezone (e.g., "Asia/Dhaka") and last_meal_check.server_config: Stores the current active persona_mode.Context Management: Python collections.deque for short-term (30-min) rolling conversation memory.📂 3. Folder Skeleton (Modular Architecture)The project follows a "Cog" based structure to ensure high complexity doesn't lead to messy code.discord_bot/
├── .env                    # Secret API tokens & Discord keys
├── .gitignore              # Ignore venv, .env, and .db files
├── main.py                 # Bot entry point & Cog loader
├── database.db             # SQLite persistent storage
├── requirements.txt        # pip dependencies
├── cogs/                   # Modular feature sets
│   ├── ai_brain.py         # Gemini logic & Persona injection
│   ├── vision.py           # Image analysis logic (Gemini Vision)
│   ├── scheduler.py        # 2-hour Bumps, Meal Checks (Onee-san mode)
│   ├── memories.py         # Database handlers (Facts, Timezones)
│   ├── social.py           # Mention reactions, !mode switching
│   └── utilities.py        # Summarizer, Portfolio checks
└── utils/                  # Helper functions
    └── db_handler.py       # Async SQL wrappers

Conversation & AI Core30-Minute Context Window: Use deque to maintain a rolling history of the last 15-20 messages.Chain Memory: Identifies who said what to distinguish between users.Visual Cortex: Uses Gemini Vision to analyze uploaded images when mentioned.B.
