# Agent Instructions

This repository uses `features.md` as the canonical, detailed feature inventory. Keep it accurate.

When you make changes:
- Update `features.md` for any feature additions, removals, behavior changes, or command changes.
- Update the folder skeleton in `features.md` if files or directories are added, removed, or renamed.
- Update configuration and database sections in `features.md` if env keys, tables, or schema change.
- If a change does not affect features or structure (e.g., comments or formatting only), no update is required.

Always prefer ASCII in `features.md` edits.
